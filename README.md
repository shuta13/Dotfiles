# Dotfiles

## Setup

```
cd scripts/

./setup.sh
```

セットアップ時に Homebrew の `go` / `gh` / `mise` / `neovim` と、mise で管理する Node.js LTS がインストールされます。

## Misc

- Homebrew は1番安全な方法でいれる
- Google IME
  - インストール後に、サインアウト→サインインすると適用されるかも
  - 設定
    - 予測変換出すやつをオフに
- iTerm
  - <https://www.nerdfonts.com/font-downloads> から、SauceCodeProをダウンロードしてインストール
    - 設定からフォントを切り替えると適用
  - 設定
    - <Reuse previous session's directory> で、タブ分割したときに元のDir維持
    - Status Barから時計の表示。DnDで操作するやつ
  - Cobalt2 Theme
    - <https://github.com/wesbos/Cobalt2-iterm/blob/master/cobalt2.itermcolors> をダウンロード
    - 設定のColorsからimport
